# 🚀 OneStep – Daily Habit & Task Tracker

**OneStep** is a modern, minimal, dark‑themed habit & task tracking web app focused on helping you improve **1% every day**. It is fast, distraction‑free, and works entirely offline using browser storage.

🌐 **Live Demo:** 👉 [https://avinash-singh-2007.github.io/OneStep/](https://avinash-singh-2007.github.io/OneStep/)

---

## ✨ Key Features

### 🧩 Habit & Task Management

* Add, edit, and delete daily tasks
* One‑click mark as completed
* Clean card‑based layout with smooth hover actions

### 🏷️ Category System

* Default categories: **Health, Work, Mind, Personal**
* Create your own custom categories
* Filter tasks instantly by category

### 📊 Progress Analytics

* **Daily completion percentage** with circular progress gauge
* **Monthly average score** (last 30 days)
* **Daily history log** for long‑term tracking

### ⏱️ Real‑Time Interface

* Live digital clock
* Dynamic date display

### 💾 Offline & Persistent

* Uses **LocalStorage** (no backend required)
* Data remains saved after refresh or browser close

### 📱 Responsive Design

* Fully responsive for desktop, tablet, and mobile
* Smooth scrolling and adaptive layout
